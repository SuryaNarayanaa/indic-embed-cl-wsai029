# Stage 1 / Stage 2 Fine-Tuning and Decoder Experiments

Code for the balanced (Stage 1) and weak-pair weighted (Stage 2) LaBSE
fine-tuning experiments, plus the decoder-to-encoder conversion
experiments (Approach A/B), reported in our paper
"Balanced and Weak-Pair Weighted Fine-Tuning of LaBSE for Direct
Indic-Indic Sentence Alignment."

See README.md and APPROACH_B_README.md in this folder for setup and
exact commands to reproduce every result in the paper.
